# Manual Usuario - Central Boxing

1. Crear PIN 4 cajas en Login (puedes pegar el PIN completo; backspace retrocede de caja). Tras entrar con PIN se ofrece activar huella; tambien en Ajustes > Seguridad. Si la huella esta activa, al abrir la app entra directo; el PIN sigue funcionando como respaldo. Cerrar sesion desde el icono logout del Dashboard (pide confirmacion).
2. Dashboard: agregar alumno con foto (camara prioritaria), inscripcion hoy editable, vencimiento +1 mes readonly, nacimiento opcional. Fechas se escriben como `01012000` y se formatean solas a `01/01/2000`; fechas imposibles (31/02) se rechazan.
3. Filtros todos/al dia/por vencer/vencido con scroll, swipe por vencer para WhatsApp. Menu Ordenar: por vencimiento, alfabetico A-Z o mas recientes.
4. Detail: ver foto Hero tap zoom, editar, marcar pagado, eliminar pago (pide confirmacion y recalcula el vencimiento desde la inscripcion), WhatsApp con 2 opciones: recordatorio de pago (mensaje ⏰/🚨) o bienvenida + grupo de Tehuacan, historial, eliminar alumno.
5. Ajustes: modo oscuro manual, huella (requiere biometrico en el dispositivo), probar notificacion, backup JSON en Descargas, importar, export CSV/PDF todos/por vencer/vencido.
6. Notificaciones diarias 09:00 y Workmanager.
